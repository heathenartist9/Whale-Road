# Whale-Road

A Viking fleet saga for the phone. Start with one longship, name your captains, and live the story. It can be added to the home screen and played offline.

Play: https://heathenartist9.github.io/Whale-Road/

Also: [Gavel Fever](https://heathenartist9.github.io/Whale-Road/judge/), a TV courtroom game for the phone.
